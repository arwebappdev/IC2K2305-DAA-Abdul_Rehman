## About This Repository

This repository contains practical implementations and laboratory assignments completed as part of the Design and Analysis of Algorithms (DAA) coursework.

The experiments focus on implementing fundamental algorithms and understanding their working principles, time complexity, space complexity, and performance.

The repository covers algorithm design techniques such as Divide and Conquer, Greedy Method, Dynamic Programming, Graph Traversal, Backtracking, Exhaustive Search, and Branch and Bound.

All practical implementations are written in **C++**.

## Course Units

| Unit   | Topics                                                                                                                        |

| Unit 3 | Greedy Method, Fractional Knapsack, Job Sequencing, Prim's Algorithm, Kruskal's Algorithm                                     |

| Unit 5 | Tree Traversals, Graph Representation, Breadth-First Search (BFS), Depth-First Search (DFS)                                   |
| Unit 6 | Backtracking, N-Queens Problem, Sum of Subsets, Constraint Satisfaction Problems                                              |
| Unit 7 | NP-Hard and NP-Complete Problems, Exhaustive Search, Branch and Bound, 0/1 Knapsack, Travelling Salesperson Problem           |

## Execution

### 1. Clone the Repository

```bash
git clone REPOSITORY_URL
```

### 2. Navigate to the Repository

```bash
cd IC2K2305-DAA-Abdul_Rehman
```

### 3. Navigate to an Experiment Folder

For example:

```bash
cd Unit07-NP-Hard-NP-Complete/01-Exhaustive-Search
```

### 4. Compile the C++ Program

```bash
g++ main.cpp -o program
```

### 5. Execute the Program

On Windows:

```bash
.\program.exe
```

**Note:** Each experiment contains its own implementation and execution instructions in its respective README.md file. Some experiments may require specific input formats.
